SDK-123 · Authoring feel

Can Asset files and typed GFX feel like one coherent Feature?

Drive a real Dawn of Ascension slice from filesystem capture through Feature placement and canonical .gfx output. The question is whether the public calls make the ownership, references, minted names, and file grouping feel obvious before any production implementation is fixed.

Throwaway prototype

The slice

Two sensor sprites from Dawn’s interface/doa_required_components.gfx, plus the tier-6 mesh and three particles from the mixed gfx/particles/doa_kinetic_artillery_particles.gfx. Six real dependency files are represented with their observed byte lengths and SHA-256 identities.

Revised after the first reaction

Ordinary projects set "assetsDirectory": "assets" once. Generated wiring captures and places the whole mirrored tree; authored content keeps today’s textureFile: "gfx/…" spelling. The Fold validates that one string against captured and vanilla paths. Explicit assetFile remains only for standalone use or a source that cannot mirror its destination.
