A mod is ordinary TypeScript. The file below is complete: it creates a mod,
defines one technology, and compiles the result. The `name` and `desc` fields
become localization on their own — one definition produces both the technology
file and the localization file.

<PairedExample name="first-technology" />

The TypeScript tab is the whole source file. The PDXScript tab shows every file
the SDK produces from it, each under the path it takes inside the mod.
