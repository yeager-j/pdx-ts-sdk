Reference pages are keyed to the SDK's content registries, not to the game's folders — the two
do not map one to one in either direction. Each page states what the concept is in game terms,
shows a compiled example, and lists its fields.

They are not written yet. [Coverage](/reference/coverage/) lists every registry that will get
one, the game folder each writes to, and the concepts the SDK cannot author at all.
