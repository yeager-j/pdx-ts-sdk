# @pdx-ts/docs-site

The user-facing documentation site for `@pdx-ts/sdk`, built with [Astro
Starlight](https://starlight.astro.build/). Private and local-only: there is no deploy wiring
yet.

```sh
npm run docs:dev      # serve at http://localhost:4321
npm run docs:build    # static build into dist/
npm run docs:preview  # serve the built site
```

The sidebar has two sections, both autogenerated from their directory under
`src/content/docs/`:

- `guides/` — hand-written concept pages.
- `reference/` — one page per content registry.

## Why this package is outside the root TypeScript program

Every other workspace member typechecks in the repository's single `tsc --noEmit` program. This
one cannot: Astro generates the types for its virtual modules into `.astro/types.d.ts` during a
build, and `.astro` components are not TypeScript files. So the root tsconfig excludes this
directory and the package runs `astro check` as its own `typecheck` script, which the root
`npm run typecheck` calls through to.

## Examples

Docs examples will live in this package, colocated per page and referenced by name from the
page that uses them. They are pedagogy — separate from the calibration corpora in the
repository's root `examples/` directory. The paired-example component and its compile gate come
with SDK-185.
