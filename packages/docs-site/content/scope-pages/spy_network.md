# Spy network

A spy network is the espionage-state context for a network and its assets and operations. Scripts
can change network level, create or destroy assets, iterate operations, and store permanent or timed
network flags. It is the operational frame for covert activity against a target.

## Common entry points

Common entry points include links from espionage operations or spymaster envoys and typed
espionage callbacks that supply a `SpyNetworkScope`.
