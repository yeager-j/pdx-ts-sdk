A **councilor** definition describes a council position: which countries can
use it, which leaders can fill it, and which modifiers it grants. The SDK
writes definitions under `common/governments/councilors/`.

## Define a council position

`leaderClass` is required. `possible` runs in country scope, while
`isLeaderPossible` and `aiHiringWeight` run in leader scope:

<PairedExample name="councilors" />

The generated contract describes `modifier` as a country modifier multiplied
by the assigned leader's level. Use `triggeredCountryModifier` when the
position needs conditional country modifiers. Test the final values in
Stellaris because the SDK checks the modifier shape, not council calculations.

Set `civic` when a position belongs to a civic. Without a civic, provide `icon`
when the position needs its own sprite. `conditionalTooltip`,
`customUnlockTitle`, `customTooltip`, and `customTooltipWithModifiers` each
name a localization key: write the display text and the SDK keys it for you, or
pass a reference to an entry that already exists.

Vanilla councilors use `optional` and AI weights to guide assignment, but the
generated contract does not establish every UI or AI behavior. Test position
unlocking, leader eligibility, assignment, replacement, and save/load in the
supported game version.

## API and vanilla references

- [`CouncilorDef`](https://github.com/yeager-j/pdx-ts-sdk/blob/main/packages/sdk/src/generated/councilor.ts)
  is the generated definition used by `mod.councilor`.
- [`vanilla.councilor`](https://github.com/yeager-j/pdx-ts-sdk/blob/main/packages/sdk/src/generated/vanilla-refs.ts)
  provides checked references to vanilla councilor ids.

Councilors have no patch surface. `mod.patchCouncilor` does not exist.
