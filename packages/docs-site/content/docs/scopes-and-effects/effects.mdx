The full effect inventory is generated from the same metadata as the scope pages. Ordinary effects,
structural methods, event-fire methods, and scope transitions remain separate because they have
different authoring roles.

This initial index shows the shared row format with one universal effect and one scope-specific
effect. Use a scope page to see every method legal on that generated interface.

<EffectReferenceTable
  rows={buildEffectPreview(["activateGateway", "setPlanetName"])}
  caption="Effect row preview"
  showAvailability
/>

The availability column describes the generated SDK contract. The game key is the fixed PDXScript
key when the method has one, while the TypeScript signature is the author-facing call shape.
