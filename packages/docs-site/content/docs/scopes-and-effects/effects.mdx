This is the effects-first view of the same generated metadata the scope pages use. Each method has
one entry here: what it writes, what it accepts, and where you can call it. A scope page answers the
other question — what is legal on the interface you are holding.

Entries fall into three categories. An **effect** writes one PDXScript key. A **structural** method
is control flow — `if`, `random`, `whileLoop` — that shapes the block it wraps. An **event-fire** method
fires an event; its availability says where the fire call is legal, and its own entry says which
scope the fired event's body runs in, which is a different scope.

Availability is either every scope or an explicit list. They are separate statements: a method
marked as available everywhere is universal by construction, not a list that happens to name all of
them. Scopes link to their reference page where one is written.

Each row has a stable `#effects-methodName` anchor — `#effects-addResource` — that survives
filtering and paging, so a link to a method keeps working.

Scope links, the properties that move you from one scope to another, are not methods and are not
listed here. They live on the scope pages, under the transitions each scope offers.

"Every method" means the SDK's current authoring surface, generated from the vendored rules. It is
not the set of effects Stellaris supports.
