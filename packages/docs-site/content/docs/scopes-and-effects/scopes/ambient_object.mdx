An ambient object is a placed object in a star system. Scripts can create or destroy it, position
it, and store permanent or timed flags on it. Its visual or gameplay meaning is defined by the
object and its surrounding game content rather than by the scope type.

## Common entry points

Common entry points include ambient-object creation callbacks, system iterators, and the
`lastCreatedAmbientObject` link.
